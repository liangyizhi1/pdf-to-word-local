# Contributing

Thank you for helping improve PDF to Word Local.

Before opening an issue, remove confidential information from samples, search existing issues, and state whether the PDF is searchable, scanned, or password-protected. Include the operating system, Python version, page count, and generated conversion report.

Pull requests should stay focused, include tests for behavior changes, and explain user-visible changes and known limitations. Test fixtures must be original, public domain, or generated in code. Never commit private or copyrighted PDFs without permission.
